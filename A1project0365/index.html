What I Built

งานชิ้นนี้คือเว็บไซต์ Learning Portfolio แบบหน้าเดียวที่รวบรวมข้อมูลส่วนตัว ข้อมูลการสร้างชิ้นงาน และสรุปความรู้จากการเรียนรู้ด้วยตนเอง

วิเคราะห์การทำงาน (Client & Server):

ตอนที่ผมเปิดไฟล์เว็บไซต์จากคอมตัวเอง Chrome จะเปิดไฟล์ HTML และ CSS ที่อยู่ในเครื่องโดยตรง ดังนั้นตอนนี้ยังไม่ได้มี Server จากอินเทอร์เน็ตเข้ามาเกี่ยวข้อง

เหตุผล: เพราะเว็บเบราว์เซอร์บนเครื่องคอมพิวเตอร์ของเราทำหน้าที่เป็น Client ที่อ่านและประมวลผลไฟล์ HTML และ CSS โดยตรงจากระบบจัดเก็บข้อมูลในเครื่องโดยไม่ได้ส่งคำขอ (HTTP Request) ผ่านเครือข่ายอินเทอร์เน็ตไปยังเครื่อง Server เครื่องอื่นเพื่อดึงข้อมูลกลับมา

How I Built It

ขั้นในการพัฒนางานชิ้นนี้มีดังนี้:

  1. วางแผนเนื้อหาและเตรียมไฟล์สื่อต่างๆ
  2. เขียนโครงสร้างเว็บโดยใช้ Semantic HTML
  3. จัดแต่งหน้าตา ความสวยงาม และการจัดวางเลย์เอาต์ด้วย CSS
  4. ทดสอบลิงก์และการแสดงผลผ่านเว็บเบราว์เซอร์เพื่อไม่ให้มี Broken Link

เครื่องมือและแหล่งข้อมูลที่ใช้เรียนรู้:

  • โปรแกรมเขียนโค้ด: VS Code (Visual Studio Code)
  • แหล่งข้อมูลที่ใช้ศึกษา: W3Schools และ MDN Web Docs

Reflection

1. ปัญหาหรือความท้าทายที่พบและวิธีแก้ไข:

ปัญหาคือการจัดตำแหน่งองค์ประกอบและการเชื่อมโยงไฟล์ CSS รวมถึงรูปภาพด้วย Relative Path ให้ถูกต้องโดยไม่เกิด Broken Link แก้ไขโดยการศึกษาลำดับโฟลเดอร์อย่างละเอียดและใช้เครื่องมือตรวจเช็กบนเบราว์เซอร์

2. ความเข้าใจเกี่ยวกับการพัฒนาเว็บไซต์ที่มากขึ้น:

เข้าใจความแตกต่างและบทบาทหน้าที่ของ HTML และ CSS รวมถึงความสำคัญของ Semantic HTML ที่ช่วยให้เบราว์เซอร์และระบบค้นหาเข้าใจโครงสร้างเว็บได้ดีขึ้น

3. สิ่งที่อยากปรับปรุงหรือเพิ่มหากพัฒนาต่อ:

ผมอยากลองเพิ่ม JavaScript เพื่อทำให้เว็บไซต์มีความเคลื่อนไหวโต้ตอบกับผู้ใช้งานได้
